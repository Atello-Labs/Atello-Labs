
# Atello Labs

> Software. Firmware. Hardware.

Atello Labs is a research and engineering laboratory focused on low-latency utilities, embedded firmware, and custom physical hardware. 

We build fast, zero-bloat primitives from fundamental principles.

---

### Focus Areas

* **Software:** High-performance CLI tools, local-first data systems, and developer infrastructure.
* **Firmware:** Bare-metal microcontroller code, real-time control, and low-level protocol drivers.
* **Hardware:** Custom mechatronics, rapid physical prototyping, and PCB design.

*Based in NY*
